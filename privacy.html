隱私權政策

生效日期：2026 年 10 月 6 日

本政策說明 聲流科技（以下稱「我們」）在提供 WaveScope 服務（以下稱「本服務」）時，如何取得、使用、保存與刪除資料。本服務是供我們團隊內部使用的行銷成效分析工具，不對外開放註冊。

一、我們取得哪些資料

來源內容
Instagram 公開商業資料（Meta Business Discovery API） Instagram 專業帳號（商業或創作者帳號）公開的帳號名稱、粉絲數、貼文數，以及公開貼文的網址、發布時間、讚數、留言數與 Reels 觀看數。
創作者授權資料（Instagram Insights） 只有在創作者主動點選授權連結並同意後才會取得，包括貼文的觸及、觀看、收藏、分享等洞察數據，以及粉絲的年齡、性別、地區分布（受眾輪廓，為統計資料，不含個別粉絲身分）。
Hashtag 公開貼文（Meta Hashtag Search API） 使用特定 hashtag 的公開貼文的網址、內文、發布時間、讚數與留言數。此 API 不提供發文者帳號名稱，我們也不會另外取得。
團隊手動輸入 合作費用（現金、禮券、樣品）、約定交付、報價，以及從創作者處取得的後台數字（例如分享數、收藏數、限時動態觀看數）。Threads 貼文的網址與成效數字也只以手動方式登錄。
創作者提供的後台截圖 創作者主動提供給我們的 Instagram 或 Threads 後台截圖，作為合作成效數字的依據，並用來預填上述手動輸入的數字。截圖可能含有受眾輪廓（年齡、性別、地區的統計分布），不含個別粉絲身分。

我們只透過 Meta 官方 API 取得資料，不使用爬蟲或任何規避平台防護的方式。我們不取得、也不保存創作者的 Instagram 密碼。

二、我們如何使用資料

資料只用於：評估與創作者合作的成效、比較與挑選合作人選、挑選值得加熱的內容，以及觀察議題聲量變化。我們不會出售、出租或轉讓任何從 Meta 平台取得的資料，也不會將資料用於廣告受眾建立、個人側寫或任何與上述目的無關的用途。

三、資料的保存與保護

  • 創作者授權取得的存取權杖（access token）以加密方式保存，並只用於取得該創作者授權範圍內的資料。
  • 服務只透過 HTTPS 存取，帳號密碼以雜湊方式保存，僅限團隊內經授權的成員使用。
  • Hashtag 公開貼文保留 180 天，貼文內文在 90 天後清除。
  • 停止觀察的創作者帳號，其一般貼文資料在停止觀察滿 1 年後刪除。
  • 合作貼文的成效數據隨活動紀錄保存，作為結案與日後評估的依據。
  • 創作者後台截圖存放在本服務的主機上，只有登入的團隊成員看得到。刪除對應的手動輸入紀錄或合作貼文時，截圖會一併刪除；上傳後沒有用於任何手動輸入紀錄的截圖，30 天後自動刪除。

四、撤銷授權與刪除資料

授權過的創作者可以隨時用以下任一方式撤銷授權並要求刪除資料：

  1. 在 Instagram 或 Facebook 的「設定 → 應用程式和網站」中移除本服務。我們收到 Meta 的資料刪除通知後，會刪除您的存取權杖、Insights 數據與受眾輪廓資料。
  2. 寄信至 hello.wavescope@gmail.com，註明您的 Instagram 帳號名稱。我們會在確認身分後 30 天內完成刪除並回覆您。

若您希望刪除您提供給我們的後台截圖，也可以來信要求，我們會在 30 天內刪除並回覆您。

撤銷授權後，我們仍可能保留透過公開 API 取得的公開數據（例如公開貼文的讚數），因為這些資料任何人都能公開查看。若您希望一併刪除，也可以來信要求。

五、第三方

本服務的資料來源為 Meta Platforms, Inc.，其資料處理方式請參閱 Instagram 隱私政策。

  • 雲端主機：資料保存在 Amazon Web Services（AWS Lightsail，東京區域）的主機上。
  • 截圖辨識：啟用自動辨識時，創作者後台截圖會傳送給 Anthropic 的 Claude API，只用於讀出截圖上的數字並預填表單，預填結果須經團隊成員核對後才會保存。從 Meta API 取得的資料不會傳送給 Anthropic。

除上述服務提供者與依法令要求外，我們不會將資料提供給其他第三方。

六、政策更新

本政策若有修改，會更新本頁的生效日期。重大變更時，我們會通知已授權的創作者。
